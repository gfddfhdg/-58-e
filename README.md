# 同城信息小程序便民信息小程序58同城商家入驻信息发布招聘小程序

源码地址：ym7k.com/19289/

## 🧱 技术栈

- 前端：UniApp（uView）｜微信小程序 + H5（可选 APP）
- 后端：FastAdmin / ThinkPHP6 + MySQL + Redis
- 配套：PC 管理后台，可选 PC 同城官网
- 环境：PHP7.4–8.1、Nginx、地图、OSS、微信支付、短信

## 📦 四大核心板块（后台开关）

✅ **便民信息发布（个人发帖）**
个人实名即可发帖，后台自定义分类：租房售房、二手转让、顺风车、寻物寻人、店铺转让、家政维修、搬家、征婚等；图文 / 短视频发布，设置全城 / 仅本街道可见。

✅ **招聘求职专区（独立子模块）**
求职者：创建简历、附近岗位、全职 / 兼职 / 日结筛选、一键投递、收藏、私信、脱敏电话、简历隐私屏蔽。
企业 / 包工头：资质审核，发布岗位、人才库检索、邀约、面试状态管理、岗位置顶刷新。

✅ **商家入驻（本地黄页门店）**
个体户、实体店入驻，店铺主页、营业时间、相册、联系电话；支持入驻年费套餐、优惠券、上门预约、团购活动；商家可批量发布本店招聘、服务信息。

✅ **平台增值运营**
置顶、刷新、加急、会员套餐、首页广告、签到积分、分享推广。

## 🙋 普通用户端（小程序）

- 微信一键登录、手机号实名
- LBS 自动定位，距离优先排序，城市切换
- 信息浏览、筛选、收藏、私信聊天、评论、举报
- 发布管理：编辑、下架、付费推广
- 个人中心：我的帖子、收藏、投递记录、订单充值、消息通知

## 🏪 商家入驻后台

- 营业执照审核，开通线上店铺
- 店铺装修、上架服务、发布本店招聘
- 线索汇总：咨询、预约、简历投递统一管理
- 购买推广套餐：店铺置顶、招聘置顶、首页广告位

## 🛠️ PC 运营总后台

- 分类自定义：新增、修改类目，每个类目独立发布表单
- 内容审核：便民帖、招聘、商家资料，敏感词风控、黑名单
- 财务：充值、套餐订单、提现对账、流水
- 变现配置：发帖收费、置顶价格、商家入驻年费、会员权益
- 多城市分站（可选）：分站独立管理员、独立广告、收益分成
- 数据统计：发帖量、岗位量、访问、咨询转化报表
